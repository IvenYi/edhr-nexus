# 表单流程版本引用治理用户确认 v5

日期：2026-09-08

来源：用户与主智能体关于“作业流程表单填报节点引用表单流程版本”的连续业务讨论确认。

已确认结论：

- 用户在作业流程中应选择“表单流程”，系统内部固定到当前已发布版本；已发布作业流程版本锁定该引用，不因表单流程后续升版自动改变。
- 作业流程表单填报节点必须选择业务单据，但表单流程本身可选；不需要审批流程时可以不配置表单流程并发布。只有实际绑定表单流程后，系统才校验该流程的字段权限、按钮事件和签名字段绑定。
- 用户清除表单流程绑定后，绑定级字段权限和事件绑定应一并清理，避免隐藏配置在无流程状态下继续影响发布。
- 表单流程发布新版后，不自动升级已发布作业流程；如果业务需要采用新版，应通过新的作业流程版本完成受控切换。
- 表单流程侧需要影响分析，能够查看某个流程版本正在被哪些作业流程版本和表单填报节点引用。
- 已被作业流程版本中的表单填报节点引用的表单流程禁止删除；删除前必须先解除相关作业流程引用。
- 作业流程草稿引用旧版本时，必须明确提醒用户已有新版，并提供升级到当前发布版本的动作。
- 点击“升级”只是修改当前画布中的草稿节点配置，不等同于保存草稿；用户仍应能刷新、关闭不保存或继续编辑。只有用户显式点击“保存草稿”后，系统才持久化该次升级并重建使用情况投影。
- 升级前必须校验字段权限、按钮事件和签名字段绑定是否仍与新版兼容；不兼容时不能静默替换，保存和发布时仍需要对应校验兜底。
- 选择填充签名字段时，目标字段只能是表单中的签名类型字段；普通文本等非签名字段不能作为签名填充目标。仅声明电子签名而不填充字段时，不需要绑定目标字段。
- 后端暂时保留历史已发布版本可被显式引用的能力，为后续管理员级版本维护保留口子；普通前端入口仍只展示当前发布版本。
- 使用情况是作业流程图配置的查询投影，由系统保存作业流程图时重建，不是用户手工维护的第二份配置事实。

边界：本证据只确认配置层、版本治理和影响分析；不表示表单流程实例、外层作业同步推进、运行时字段权限解析或电子签名副作用已经实现。
