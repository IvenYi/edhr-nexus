# 生产表单流程权限组与节点事件确认（当前方案）

日期：2026-09-07

本记录是用户确认的配置层边界，不代表表单流程运行时权限解析、按钮动作或事件执行已经实现。

- 填报阶段按权限配置组设置字段权限；一个填报权限组可以包含多个用户、部门或角色主体，权限按组设置一次，不按成员逐个重复配置。
- 审批阶段每个审批节点视为一个权限配置组；该节点内可以配置多个审批主体，字段权限按该审批节点统一设置，不将审批主体平铺成多个权限组。
- 填报组和审批节点组都可配置统一默认权限及绑定表单后的字段例外；未配置主体的开放操作语义保持现有规则。
- 每个开始/填报或审批节点的每个按钮可以独立声明签署事件，因此不同按钮可以绑定不同的签名字段；没有配置事件的按钮不展示节点事件配置区域。
- 作业流程表单填写节点不再单独展示或配置内置事件；它只在绑定表单后为已声明的事件选择真实稳定 `fieldId`。
